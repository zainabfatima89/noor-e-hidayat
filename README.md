# نورِ ہدایت (Noor-e-Hidayat)

Qurani ayat ka jar box + Islamic bayanat links. Static website (HTML/CSS/JS), GitHub Pages par free hosting.

## Files
- index.html  : main page (SEO tags + JSON-LD)
- style.css   : design
- script.js   : jar box logic aur ayat ka data
- hero.svg    : main picture
- favicon.svg : tab icon
- sitemap.xml, robots.txt : Google ke liye
- 404.html    : "page not found"

## Deploy
Repo name: `noor-e-hidayat` -> Settings -> Pages -> Branch: main / (root) -> Save.
Live URL: https://zainabfatima89.github.io/noor-e-hidayat/
